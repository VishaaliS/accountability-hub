# ⚒️ Accountability Hub

A gamified, real-time cooperative habit-tracking app for two friends. Work together against a shared "boss block" instead of competing against each other.

## Features

- 🎮 **Gamified Task System**: Tasks are "ore blocks" with different rarity levels (Diamond, Gold, Bronze, Stone)
- 👥 **2-Player Co-op**: Only two users per partnership - true accountability, no distractions
- ✅ **Real-Time Sync**: See your partner's tasks update instantly using Supabase Realtime
- 🔐 **Partnership Verification**: Both users must accept before connecting
- 📊 **Progress Tracking**: Click tasks to "mine" them and complete your goals
- 💾 **Persistent Data**: All tasks and partnerships saved in PostgreSQL

## Tech Stack

- **Frontend**: React + Vite
- **Styling**: CSS3 + Tailwind CSS
- **Backend**: Supabase (PostgreSQL + Auth)
- **Hosting**: Vercel

## Getting Started

### Prerequisites

- Node.js (v16+)
- npm or yarn
- Supabase account

### Installation

1. Clone the repo:

```bash
git clone https://github.com/YOUR_USERNAME/accountability-hub.git
```
